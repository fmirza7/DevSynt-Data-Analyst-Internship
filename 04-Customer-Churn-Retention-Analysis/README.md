# Customer Churn & Retention Analysis

Analysis of customer churn patterns using Python and Power BI, including exploratory analysis, statistical testing, customer segmentation, and revenue-at-risk analysis.

## Key Findings

- Overall churn rate: **26.54%**
- Highest contract churn: **Month-to-month (42.71%)**
- Highest tenure-group churn: **0–12 months (47.44%)**
- Churned customers average **$74.44/month** vs. **$61.27** for retained customers
- Monthly revenue at risk: **$139,130.85**

## Tools

Python, Pandas, NumPy, Matplotlib, SciPy, Power BI
